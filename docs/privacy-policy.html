划词翻译隐私政策

本页说明 Microsoft Edge 扩展「划词翻译」（Selection Translator）如何处理数据。扩展在你的浏览器里运行。作者没有自己的服务器，扩展不会把选中的文字或译文发到作者的服务器。

扩展处理哪些数据

扩展只在你主动划选文字，或使用强制翻译（快捷键、右键菜单）时读取当前选区的文本。

本地保存在 chrome.storage.local（键名 estSettings）里的内容包括：开关、语言、引擎、语气、主题、是否保留专名；你填写的 API 密钥；最近约 50 条翻译和最多约 100 条收藏；黑名单网站的主机名。扩展不使用 chrome.storage.sync。

选中的文字会发给谁

翻译请求由扩展自己的后台脚本发出。选中的文字和语言代码会发送到你当前选择的翻译引擎。DeepL 与 OpenAI 兼容接口还会带上语气要求。启用「尽量不翻译专名」时，网址、邮箱、全大写缩写和连续首字母大写的专名会先换成占位符。扩展作者不接收、不记录这些请求。

引擎请求发往密钥
MyMemory（默认）https://api.mymemory.translated.net/get不需要
Google 翻译https://translate.googleapis.com/translate_a/single（非官方接口）不需要
Bing 翻译https://www.bing.com/translator 与 https://www.bing.com/ttranslatev3不需要
DeepLhttps://api-free.deepl.com 或 https://api.deepl.com只存在本机
OpenAI 兼容你填写的地址，默认 https://api.openai.com/v1/chat/completions只存在本机
LibreTranslate你填写的地址，默认 https://libretranslate.com/translate可选，只存在本机
Azure 翻译https://api.cognitive.microsofttranslator.com/translate只存在本机

首选引擎失败时，扩展会按 MyMemory、Google、Bing 的顺序改用其余免密钥引擎，并在面板上说明实际使用的是哪一个。各引擎如何保存文字，以其自己的隐私政策为准。

不出售数据，默认没有遥测

  • 作者不出售、不出租、不交换选区、译文、历史、收藏或密钥。
  • 默认没有遥测：没有分析脚本，没有广告，也没有可开启的遥测开关。
  • 密码框中的文字不会读取。代码块和常见代码编辑器中的选区不会送去翻译。

卸载扩展会删除浏览器为它保存的本地数据。选项页也可以清空历史、收藏和密钥。

English

Selection Translator runs in your browser. The author runs no server for this extension. Selected text and translations are not sent to the author.

The extension reads text when you select it or force a translation. Settings, API keys, recent translations, favorites, and blacklisted hostnames stay in chrome.storage.local under estSettings. Nothing is written to chrome.storage.sync.

Selected text is sent only to the engine you choose. The default is MyMemory (api.mymemory.translated.net). Google (translate.googleapis.com) and Bing (www.bing.com) are the keyless fallbacks. Also available: DeepL (api-free.deepl.com or api.deepl.com), an OpenAI-compatible URL you enter (default api.openai.com), LibreTranslate (default libretranslate.com), or Azure Translator (api.cognitive.microsofttranslator.com). API keys remain on the device and are attached only to that provider's request.

The author does not sell, rent, or trade this data. Telemetry is none by default. Uninstall the extension to delete its local storage.
