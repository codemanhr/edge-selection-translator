语气 Style

语气对 DeepL（formality）和 OpenAI 兼容接口有效。Bing、Google、MyMemory、LibreTranslate 和 Azure 会提示已按普通风格翻译。

API 密钥 Stored only on this device

密钥只保存在 chrome.storage.local。选择这些引擎或填写自定义地址时，浏览器会询问是否允许访问对应网站。公共 LibreTranslate 实例经常需要密钥。

快捷键 Shortcuts

    这里只改变界面上的写法。浏览器登记的按键仍是 Alt，在 Mac 上对应 Option。可在 edge://extensions/shortcuts 里修改；如果按键没有反应，多半是被浏览器占用了。
